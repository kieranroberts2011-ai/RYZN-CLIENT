# RYZN Client

RYZN Client is an independent Windows launcher for Minecraft Java Edition.

## Features
- Microsoft sign-in through the system browser
- Minecraft 1.21.11 and Fabric installation
- Separate instances for mods, saves, and settings
- Built-in Modrinth browsing with original project icons
- Compatible mod installation with required dependencies
- Responsive interface and fullscreen support

## Development status
The Windows launcher, Minecraft/Fabric installation, and Modrinth downloads have been tested. Microsoft authentication uses PKCE and Windows-encrypted credential storage.

Minecraft API approval is pending. Authenticated game launch and in-game companion features still require verification.

Requires an account with access to Minecraft Java Edition. Not affiliated with Mojang or Microsoft.
